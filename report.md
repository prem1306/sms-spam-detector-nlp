## Abstract

This project implements an NLP classifier that distinguishes spam SMS messages from legitimate messages. It uses word-level TF-IDF features and a Multinomial Naive Bayes classifier. On a fixed, stratified held-out split of the cleaned UCI SMS Spam Collection, the model achieved 96.71% accuracy and 84.68% spam F1. A local desktop interface allows users to classify new messages.

## Objective

Build a small, reproducible text-classification pipeline, evaluate it using class-specific metrics, and demonstrate prediction through a simple interface.

## Dataset

The UCI SMS Spam Collection contains labelled SMS messages: ham denotes legitimate messages and spam denotes unwanted messages. The downloaded file parsed into 5,574 labelled records. Case and whitespace-equivalent messages were collapsed before splitting, leaving 5,159 records. The code also excludes groups with contradictory labels; this run found none. The original data file is preserved.

## Methodology

1. Read the label and message from each tab-separated record.
2. Collapse equivalent duplicate messages before splitting to prevent direct duplicate leakage.
3. Use an 80/20 stratified train/test split with random seed 42: 4,127 training messages and 1,032 test messages.
4. Convert messages into TF-IDF word unigram and bigram vectors. Lowercasing and sublinear term frequency are enabled; default word tokenization and L2 normalization are used.
5. Fit Multinomial Naive Bayes with additive smoothing alpha = 0.5.
6. Evaluate on the held-out test messages and compare against an always-ham majority baseline.

The scikit-learn Pipeline fits the vocabulary, IDF weights and classifier exclusively on the training set. Parameters were fixed rather than selected using test performance. No stemming, stop-word removal, hyperparameter search or external LLM is used.

TF-IDF combines term frequency with inverse document frequency, assigning less weight to terms that are common across the corpus. Naive Bayes estimates the class posterior from the class prior and feature likelihoods under a conditional-independence assumption. Although fractional TF-IDF weights are an approximation to multinomial counts, they provide a useful text-classification baseline.

The model detected 94 of 128 spam messages and missed 34. It flagged no legitimate message as spam in this test split. That observed 100% precision does not guarantee perfect precision on future messages. The high accuracy partly reflects class imbalance, so spam recall and F1 provide essential context.

## Application

Run `python app.py` to enter a message into the desktop interface. The model returns ham/spam and its estimated spam probability. `predict.py` provides the same functionality in a terminal. The score is not calibrated and should not be interpreted as a guaranteed real-world likelihood.

## Limitations and future work

The dataset represents older English SMS patterns and does not establish performance on modern scams, other languages or messages from different populations. Near-duplicates with changes beyond case and whitespace can remain. One random holdout has sampling uncertainty; this project does not report cross-validation estimates. Future work could compare logistic regression and Complement Naive Bayes, evaluate character n-grams, use stratified cross-validation on training data for tuning, and evaluate once on a fresh untouched test set. Retraining on current labelled data would help assess deployment relevance.

## Conclusion

The project demonstrates a complete NLP workflow from labelled text to feature extraction, supervised training, evaluation and local prediction. Its measured results improve on the majority baseline while showing a clear remaining weakness: missed spam messages.
